# Multi DOF Prosthetic Arm

**A modular prosthetic arm built around human arm kinematics, controlled through machine learning on biosignals.**

Ongoing research project | NIT Tiruchirappalli

[Back to all projects](../README.md)

## Overview

 A modular arm based on human arm kinematics, with actuators sized from torque and load analysis and machine learning models that map biosignals to joint actuation. FEA and design for manufacturing check structural safety.

## Focus areas

- Arm design based on human arm kinematics
- Torque based actuator sizing
- Sensorized teleoperation glove for data collection and control
- Machine learning models from biosignals to joint commands
